# 新旧模型共用配置与运行

两个模型共用 `set_config.m`、`apply_config.m`、`runScenario.m`，以及相同的求解器参数与 LQR 增益计算函数。

```matlab
cfg = set_config();
cfg.showAnimation = false;

% 同一份配置分别运行原版和新版。
outOld = runScenario(cfg, 'blance_leg2');
outNew = runScenario(cfg, 'blance_leg2_RPY');
```

也可以设置默认目标：

```matlab
cfg = set_config();
cfg.model = 'blance_leg2_RPY';
out = runScenario(cfg);
```

`runScenario()` 读取 `set_config()`；`runScenario(cfg)` 优先使用 `cfg.model`，旧配置没有此字段时仍运行原版。显式的第二参数优先于 `cfg.model`。

点击任一模型的运行按钮时，只运行当前模型，并由自身的 InitFcn 调用 `apply_config(bdroot)` 读取统一配置。`set_config.m` 中的 `cfg.model` 仅选择脚本默认目标，不切换按钮所运行的模型。

需要只应用参数、不启动仿真时：

```matlab
load_system('blance_leg2_RPY');
apply_config('blance_leg2_RPY', cfg);
```

下一次直接点击运行按钮仍会重新读取 `set_config()`。临时配置请通过 `runScenario(cfg, model)` 运行；运行期间的配置覆盖值会在结束或出错时恢复。

# 本项目的姿态定义

不要套用“X 一定是前进方向”的假设。本模型在初始直立姿态下，轮轴/俯仰轴沿世界 X，前进运动沿世界 Y，竖直方向沿世界 Z。新增传感器 B 接世界，F 接机身公共框架（Rigid Transform11 的 B 侧）。

传感器采用 **Z-X-Y** 旋转序列，三个角为依次绕中间坐标系轴的旋转，正方向遵循右手定则：

| 向量元素 | 新版输出 | 定义 |
| --- | --- | --- |
| seq(1) | YAW | 第一次绕 Z 的偏航角 |
| seq(2) | PITCH | 第二次绕 X 的俯仰角 |
| seq(3) | ROLL | 第三次绕 Y 的横滚角 |
| seqd(1) | d_YAW | YAW 的时间导数 |
| seqd(2) | d_PITCH | PITCH 的时间导数 |
| seqd(3) | d_ROLL | ROLL 的时间导数 |

角度单位 rad，角度变化率单位 rad/s。新版六路姿态接口使用 Simulink Outport，Demux 后不再转回物理信号。外层端口各组所在边及排列顺序保持修改前的 RPY 布局。两个多余的增益转接块已删除：PITCH 直接连接原来的 4 个下游端口，d_PITCH 直接连接原来的 6 个下游端口；原有分支和下游线段走向保留。

## 与原版 Pitch 的关系

原版初始变换绕 Y 旋转 +90°，pitch 关节绕局部 Z 旋转 q，随后从 Rigid Transform11 的 F 侧回到 B 侧时抵消固定的 +90° 旋转。因此机身姿态为：

```text
R_world_body = Ry(90°) * Rz(q) * Ry(-90°) = Rx(q)
```

新版零姿态也抵消同一组固定变换。仅有俯仰运动时，Z-X-Y 的输出为 `[0, q, 0]`，因此在正常直立工作范围内，新 PITCH 与原 PHI 的零点、轴向及正方向一致，d_PITCH 与原 d_PHI 一致。

原版没有可运动的 Yaw、Roll，不能比较这两路在原版中的非零角值；新版沿用了原版机身框架，在此基础上增加其余两个轴的角度定义。

## 三维运动的边界

欧拉角变化率 seqd 与角速度向量 Omega X/Y/Z 是不同的量。6-DOF 解锁没有增加偏航或横滚控制器，也不会自动将平面 LQR、轮速补偿和里程估计改成完整三维算法。

例如 `wheel_carrier_rate.m` 中把连杆角速度与机身俯仰角变化率直接相加，是原平面工况的关系；同时发生横滚和偏航时，需要重新投影到实际轮轴。这里保持原算法，未把三维动态下的所有反馈量宣称为已验证。

Z-X-Y 在俯仰达到 ±90° 附近存在欧拉角奇异性，因此上述 Pitch 一致性针对直立附近的工作范围，而非任意翻转姿态。

# 新版摄像头

Camera1 的位置跟踪 `Rigid_Transform6.F`，注视目标跟踪 `Rigid_Transform6.B`（与 6-DOF Joint 的 F 是同一框架节点），向上方向保持世界 `+Z`。已移除原来对已删除 `pitch.B` 的引用。

该坐标变换保留局部 `[0,0,0.8] m` 偏移，在直立时相当于位于机身侧面世界 +X 方向 0.8 m 处。新版位置参考接在机身侧，因此会随偏航、横滚改变观察位置；世界向上约束使画面保持以世界竖直方向为上方。原版参考接在俯仰关节之前，只有平移跟随。

这是摄像头绑定关系的检查；尚未人工观看解锁后完整运动过程中的取景效果。

# 本次验证

在 MATLAB R2023a 中完成以下检查：

- 原版与新版各完成 0.02 秒零速度仿真，均返回 logsout、tout。
- 旧配置省略 model 字段、新配置通过 cfg.model 选新版、第二参数显式覆盖模型选择，均通过。
- 两个模型共用配置应用入口，运行覆盖配置在结束后恢复。
- 独立 Transform Sensor 测试覆盖零姿态、三个轴各 ±0.2 rad，以及 `[0.3, -0.2, 0.15]` rad 组合姿态，共 8 组，输出顺序及符号全部通过。
- 原版 Pitch 的坐标变换在 -0.4、-0.1、0、0.1、0.4 rad 下均验证等于 Rx(q)。

这是接口、坐标定义与短时启动验证，不是新增横滚/偏航控制的稳定性验证。原有模型的初始关节目标未完全满足等提示仍保留，未为消除提示而修改原机构参数。
